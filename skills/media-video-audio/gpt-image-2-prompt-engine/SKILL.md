# gpt-image-2-prompt-engine

> 面向电商设计师、Poster artists、Brand visual designers、UI designers、Infographic editors、Commercial photographers、Content creators等需要高质量可控出图的角色，在需要用 GPT-Image-2 生成电商主图、电影海报、信息图、Brand visual designers、UI截图、古籍国风、角色IP等场景时，通过「Prompt as Code」原子化Schema+20+工业JSON模板+四步工作流，产出结构化、可复用、可批量的生图提示词，再调用 image_generation 出图。不适用于随意生图或简单风景照。
